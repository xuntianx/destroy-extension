# 角色与五套动作

记录时间：2026-09-22。当前为可运行开发版，保留最终视觉和试听验收，不将几何测试等同于用户认可。

## 形象来源与可编辑文件

角色是灰绿色、奶油色腹部、橙色背鳍的原创卡通小巨兽，沿用本次 AI 概念图的造型方向。设计图见 `character-concept.png`，原始提示词和小样来源见 `prototype-asset-sources.md`。它不是从电影画面截取的角色，也不是把概念图直接当作动画序列播放。

`src/content/rig.js` 是可编辑矢量与关节配置的主文件。`public/assets/monster/monster.svg` 是独立 SVG 导出，可交给设计同事检查路径和部件；`npm run character:export` 重新生成它，正式构建也会自动导出。请修改主文件后导出，避免只改导出文件而被下一次构建覆盖。默认前置条件与项目一致，不依赖 Photoshop、AE 或 Lottie。

角色分为头、躯干、近／远侧腿、近／远侧手臂、前臂、尾根、尾尖和两种眼部状态。`Rig.pose` 负责关节变换、尾扫前后遮挡、脚部补偿、下颌张开和眼部渐变；爪尖、尾尖、嘴部及脚底都有测量点。插件中角色容器为 248×208 CSS 像素，SVG 坐标空间为 620×520。

## 时间线

| 动作 | 标准时长 | 关键时刻与表现 |
| --- | --- | --- |
| 登场 | 1800 ms | 70% 到达地面和落地声标记，随后身体下沉再回稳；初始不可见，不在界面加载等待中提前露出 |
| 爪击 | 1500 ms | 610 ms 命中；前摇、击出、短暂停顿、收势沿用关节关键帧 |
| 尾扫 | 1850 ms | 830 ms 命中；尾巴越过身体时换到前景，然后回位 |
| 吐息 | 3400 ms | 30% 开始喷出，46% 首次命中，86% 最后一批命中，90% 火焰结束；眼前单目标使用同一姿势轨道压缩至 1500 ms |
| 睡眠 | 3500 ms | 逐渐闭眼和低头，30% 鼾声标记，轻微呼吸；65% 后淡出，到结束完全消失 |

`src/content/motions.ts` 把登场、吐息、睡眠及其标记集中为可拖动的纯函数，爪击和尾扫复用 rig 关键帧。实际插件和动作页调用相同代码；改动动作后不会只改到展示页。登场和攻击音效通过前瞻调度发送，真实声卡输出偏差仍需实装测量。

等待只有轻微呼吸；修复时抬臂示意碎片归位，再回到中立姿势。这两项是轻量程序姿势，不新增完整动作，不安排搬运碎片。恢复页面操作后才进入睡眠。

2026-09-22 视觉迭代：吐息在 `breath-fx.ts` 中独立绘制，并与动作预览页共用。火焰使用与背鳍呼应的橙、金、奶油白三层，上下边缘分别变形；按实际喷射距离保持厚度，收尾缩短火焰且亮芯先淡，不将整段压成细线。吐息时增加后仰、抬头及下颌开口；嘴部锚点随口腔变化。近、中、远距离的实际渲染帧交给 Claude Code 独立评审，视觉结论不能用构建通过代替。

尾扫在尾巴仍位于身体轮廓外时切换前后层，前层尾根保持在头与近侧腿之后。页面恢复完成后角色保留原站位入睡，睡眠字样跟随头部，不瞬移回屏幕中间。

## 查看与验证

运行固定测试页服务后打开 `/tests/fixtures/motion.html`。可选五套动作、播放、拖动进度、查看关键帧和翻转方向。睡眠中途再切回攻击会恢复睁眼，不永久替换眼睛节点。脚部测量只比较原地姿势；登场腾空单独检查落地时刻。

本轮实际浏览器记录：爪击、尾扫、吐息和睡眠，各方向各 101 个采样姿势的脚底最大漂移不超过 0.00001 px；登场 70% 时脚底标记中心与地面线相差约 0.003 px。睡眠 50% 截图中角色闭眼、低头、身体完整可见，随后切回爪击，睁眼透明度 1、闭眼透明度 0。

这些记录证明当前几何和切换行为，不证明最终力量感、全部尺寸下无关节穿帮或用户主观满意。真实网页动作与碎裂接触、声音同步、低性能掉帧、不同缩放、真实平台仍按验收报告继续验证。
