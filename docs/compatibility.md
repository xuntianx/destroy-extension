# 支持范围与待验证项

更新时间：2026-09-23。以下区分代码实现边界与实际验证状态。用户已报告当前环境下快捷键、召唤和声音可用；Claude Code四轮评审后视觉与审美已获OK（整体8/10）。这两类证据不替代完整试听及下述具体兼容性验收。

当前主要面向普通文章页。启动时固定目标集合，最多扫描 20,000 个 DOM 元素并登记 1,800 个目标；超过范围在接管前拒绝。只处理本轮已加载内容，不追逐无限流追加项。

普通文档滚动与明确的单一大型独立滚动容器已有实现。存在多个候选主滚动区时拒绝启动。主容器被移除、视口尺寸变化、SPA URL 变化或覆盖层被移除时走异常清理；等待回答本身不视为异常。2026-09-23 调整：视口尺寸变化仍立即停止并恢复页面，但作为预期保护退出记录为 info，附带变化前后尺寸；不再使用 warn，其他故障仍保留警告。已有的 Chrome 历史警告需要手动清除，此变更不代表已支持窗口变化后继续动画。

交互控件已迁入全屏扩展页 iframe，覆盖层由模态 dialog 承载。答案在子页校验并清空，仅通过私有 MessagePort 发送完成信号。两个本地 HTTP 来源运行同一代码的短页回归中，按 Escape／Tab、输入中文、切换声音和提交没有增加原网页 window／document 的捕获与冒泡计数；加载失败会在 8 秒超时后清理。真实扩展来源、目标网站 CSP、真实 IME 和浏览器生命周期仍待实装验证，不能据此声称对所有网站脚本完全隔离。

界面完成初始化后也会通过私有通道检查响应。约 8 秒前台检查时间持续没有回应时进入 ABORTING 并清理，不进入正常回答后的恢复流程；计时从首次探测发出后计算。隐藏标签不消耗这段时间，返回后重新探测；整个浏览器长卡顿不会在一次回调里耗尽期限。本地故意不回应的 iframe 已验证能解除操作锁，这不等于真实扩展更新／渲染进程崩溃已验收。健康界面仍无限等待回答。

已知尚未充分实现／验证的部分：

- 虚拟列表节点复用、网站自带复杂弹窗、Shadow DOM 内部正文，需要单独适配。
- 已保留常见排版样式和字符串型 ::before / ::after。CSS 计数器、生成图片、列表外置标记、复杂变换、多层布局继承仍未完成保真适配。
- 独立和文字内嵌的 SVG 已纳入目标与静态副本，支持常见路径、文字、渐变、裁切及 SVG 自身内部引用；每个片段重新映射 ID，避免定义相互依赖。两组本地样例已实际对照。外部精灵、引用根 SVG 外部的 symbol、use 的复杂继承、动态 SVG、foreignObject、外部图像和复杂滤镜未完成保真适配；不复制 SVG 脚本、事件或 SMIL 动画。
- Canvas 已复制当前可绘制画面并切片，位图最大边长 1024；本地 2D Canvas 对照通过。WebGL／受限画布仍需验证；视频和 iframe 当前是简化视觉块，原元素会恢复。
- 横排普通文字使用 Range 获取实际文本行并生成裁切带；最多 8 个片段，长段落合并邻行。包含图片、表格、列表、变换或竖排的目标仍走网格。中英文混排、上下标、双向文字和一款可变 Web 字体在本地对照页已测；三站真实网页对照仍待验证。
- 已实现固定地面线、左／中／右攻击带和横向换位；下一批目标由页面滚动送入，固定／粘性内容不参与滚动追逐。动作检查页中左右朝向各 101 个采样姿势的脚部偏移小于 0.001 px；这只证明当前 SVG 几何稳定。Claude Code已依据实际尺寸导出帧认可角色、尾扫换层、髋部重叠和镜像姿势，多尺寸与低性能条件仍需单独验证。
- 五套动作在同一预览页和插件中共用：登场到地面后触发落地标记，睡眠逐渐闭眼并轻微呼吸后淡出，修复有轻量抬臂姿势。火焰、废墟、归位和睡眠经过独立评审与修改，视觉主要问题已关闭；完整流程试听尚未完成。详见 character-design.md 和 reviews/2026-09-22-claude/README.md。
- 五阶段配乐、怪兽音效、部分高频变体、交叉淡化、试听页已实现；真实音画延迟、主观试听和完整变体覆盖仍待验收。
- 解码后的 PCM 缓存上限为 64 MiB，所有标签会话共用缓存，同一文件只保留一份；同时最多两个读取／解码任务，超预算素材按加载失败处理。当前 26 个音频在本地 Chromium 48 kHz 下实测 PCM 合计 29,356,904 字节。这个预算不包含浏览器解码器临时内存、节点和进程开销；不能当作 Chrome 总内存上限。
- 攻击音效已使用最多 120 ms 的前台时钟前瞻计划，接收端转换为音频时钟；超过截止时间 50 ms 的计划丢弃。暂停、静音和阶段变化取消未来声音，普通移动目标失效时取消待播命中。计划窗口内的突发卡顿或临近命中时目标移动，仍需真实浏览器验证；不能据此承诺实际声卡输出与画面误差小于 50 ms。
- offscreen 的首次快捷键播放、静默 30 秒后重建、多标签隔离和卸载更新情形待实装验证。
- 当前环境下Chrome基础实装已有用户反馈；完整生命周期、macOS、Linux、真实IME、缩放和低性能测试仍需独立证据。

不得将本地验收页或单元测试通过当作上述功能已经完成。

局部精细碎片另外受 120 个后代节点、20,000 个文本字符和两屏面积限制；超出目标保留原节点隐藏／恢复，但不复制超大子树生成精细碎片。
