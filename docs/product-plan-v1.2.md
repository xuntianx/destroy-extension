## 1. 产品定义

2026-09-25 确认更新：中英文品牌名均为 **Destroy**，提问提交按钮均为 **Done**。图标使用生成式单枚橙红火焰。0.1.1 在此前精简浮层上调整字体、留白和控件：标题 20px/500、白底 400px 浮层、16px 圆角、15px 自适应高度输入、14px Done 按钮与 180ms 轻淡入；减少动态效果时关闭这些动效。中文固定文案使用思源黑体子集，英文使用 Manrope，两者均本地加载。设置面板同样为白底深绿强调色。网页原色、强制回答和可恢复 DOM 的约束继续有效；本文早期“摧毁 / Destroy”指同一产品历史名称。

「摧毁 / Destroy」是一款中英双语 Chrome 插件。用户面对令人烦躁的网页或工作时，按下快捷键，召唤一只卡通小巨兽。第一击发生在当前视口；怪兽直接攻击原网页文字、图片、按钮和卡片，页面自动向下滚动，把内容送入攻击带。先做局部精细破坏，达到屏数或时间预算后，用一次蓄力吐息集中处理剩余内容。

随后，插件提出一个哲理问题。用户必须提交有效回答，页面才快速重建。重建和返回原位置合计不超过实际破坏时长的三分之一，且最多 12 秒；之后恢复网页操作，怪兽睡着并慢慢消失。

核心体验是一次完整的小仪式：发泄、停顿、思考、重建、继续。

### 1.1 已确定的要求

| 项目 | 要求 |
|---|---|
| 名称 | 中文「摧毁」，英文 Destroy |
| 语言 | 中文、英文，默认跟随浏览器，可手动切换 |
| 角色 | 卡通小巨兽，具有小哥斯拉式的力量感和破坏动作 |
| 角色制作 | AI 设计形象 → 整理分部件 SVG → 前端建立关节与时间线 → 程序驱动动作；Lottie 仅作备选 |
| 入口 | 默认快捷键，以及插件面板中的召唤按钮 |
| 起点与长页面 | 从当前视口开始，默认精细推进最多约 6 屏，可调上限 8 屏；余下内容以吐息集中收尾 |
| 破坏时长 | 从第一击到废墟就绪，含收尾吐息，最多 60 秒前台有效播放时间 |
| 角色动作量 | 首版五套：登场、爪击、尾扫、吐息、睡眠 |
| 网页操作 | 破坏、等待回答、重建期间禁止操作原网页 |
| 回答要求 | 必须回答，没有跳过、超时自动恢复或快捷键绕过 |
| 重建 | 回答后快速归位，含返回原位置不超过破坏时长的三分之一，且最多 12 秒 |
| 收尾 | 页面解锁后，怪兽入睡、淡出 |
| 声音 | 优先筛选可商用素材，阶段一接入；发布包音频不超过 3 MB；找不到合适素材先询问用户，不自行使用 AI 生成 |
| 题库 | 50 道中英对照题，产品侧提供，采用本地不重复抽取 |
| 实现主线 | 直接操作原网页元素；需要碎裂时才生成局部碎片 |

### 1.2 首版边界

- 优先支持普通文章、博客、资讯页，以及含常规文字、图片、按钮、卡片的网页。
- 首版无需账号、服务器、AI 问答或用户回答分析。
- 不制作整页视觉副本，不以整页截图作为主渲染方式。
- 不删除或重建原网页，不通过刷新完成恢复。
- 无限信息流只处理启动时已加载的范围，不追逐新加载内容。
- 复杂虚拟列表、在线编辑器和多重滚动容器需要专项验证或适配。
- 网站自己的网络请求、计时器和数据更新不因插件启动而被冻结。
- 不要求逐屏精细摧毁和逐屏重建整篇长文；本轮范围内的原内容仍须统一处理并完整恢复。
- 撕咬、独立踩踏、行走巡场和搬运重建动画不进入首版；修复使用静态姿势配合光效。
- 不把「30～60 秒情绪效果最佳」当作已证实的心理规律；时长预算是待体验验证的产品决策。

## 2. 完整用户流程

### 2.1 安装与首次使用

安装后即可使用默认快捷键：

| 平台 | 默认快捷键 |
|---|---|
| Windows / Linux | Alt + Shift + D |
| macOS | Option + Shift + D |

插件面板展示名称、召唤按钮、当前生效的快捷键、语言设置、声音设置和简短说明。无需先完成设置向导。

默认跟随浏览器语言：中文环境使用中文，其余环境使用英文。用户可手动选择中文或 English，选择保存到本地。

安装时检查快捷键注册结果。如果被占用或没有成功绑定，面板提示用户进入 Chrome 扩展快捷键页面修改；召唤按钮仍然可用。

### 2.2 召唤与接管

用户在当前网页按下快捷键，或点击「召唤怪兽 / Summon the monster」。

插件先检查页面能否运行。支持时，不再弹出确认框，开始准备：

1. 记录主滚动区域、原浏览位置和当前焦点。
2. 确定本轮内容范围，保留原页面节点和表单状态。
3. 加载首批角色和声音资源。
4. 锁定原网页操作。
5. 保持当前浏览位置，在眼前内容附近建立怪兽地面线与攻击带，不先回到顶部。

原网页的链接、按钮、输入框、拖动、选择文字、手动滚动和键盘操作均被阻止。重复按快捷键不会重启、退出或生成第二只怪兽。

浏览器自身的刷新、关闭、地址栏和标签切换仍由用户控制。

### 2.3 怪兽登场

卡通小巨兽从视口边缘进入，站稳、蓄力，背鳍微亮，踩出第一道裂纹。

视觉方向：深灰绿色身体、粗线条、短爪、粗腿、大尾巴，表情认真，动作夸张。阶段一先用 AI 设计形象，整理分部件 SVG，验证一次爪击和一次尾扫的程序动画及命中标记，再扩展完整角色动作。

登场播放短乐句、落地和短低吼音效。建议登场约 2～3 秒，实际长度根据动画调整。

### 2.4 当前视口起步、攻击带推进与限时收尾

| 内容 | 怪兽动作 | 页面效果 |
|---|---|---|
| 标题、正文 | 抓扯、拍打 | 文字晃动、断裂、散落 |
| 图片 | 通用爪击 | 图片裂成可辨认的碎片 |
| 按钮、卡片 | 通用爪击或尾扫 | 压扁、倾倒、碎裂 |
| 导航、侧栏 | 尾巴横扫 | 结构断裂、坠落 |
| 最后残余内容 | 蓄力吐息 | 崩解、尘埃升起 |

破坏与动作接触点对应，不能只在网页上播放无关爆炸。

怪兽保持在视口底部附近的地面线上，按左、中、右三个方向攻击。页面向上滚动，把后续元素送入它上方的攻击带；进入范围后才命中。小范围转身或横移可以用程序动画完成，不需要逐个目标行走。

普通目标用爪击，较宽结构用尾扫，超大图和难以接近的目标可用吐息。第一批目标应来自当前视口；攻击带可在有限范围内调整，不能为了建立地面线而先滚离眼前内容。

时长和范围规则：

- 精细破坏默认最多覆盖约 6 个视口高度（含起始视口），开发参数上限 8 个；依据起始视口尺寸计算，过程中不因缩放重置预算。
- 从第一击到废墟就绪最多 60 秒，包含蓄力、吐息和沉降；切走标签页的暂停时间不计入。
- 控制器预留约 5～8 秒收尾预算，在屏数或时间预算即将耗尽时提前停止普通攻击，不能到第 60 秒才开始吐息。
- 吐息集中处理本轮剩余目标，包括起始视口上方未经过的内容和下方未精细展示的内容。屏外目标批量隐藏并保留恢复记录，不为其逐个创建碎片，不快速滚到页底假装逐屏完成。
- 页面较短时提前完成，无需刻意拖满预算；已无剩余目标则不重复执行全页清空。

长页的体验承诺改为「眼前内容精细破坏，余下内容集中收尾」，不再承诺整页每一段都有独立攻击镜头。

### 2.5 废墟与停顿

普通目标完成或收尾吐息结束后，停止滚动，在当前视口呈现废墟。碎屑沉降，怪兽吼一声、喘气、背鳍暗下；等待姿态复用静态角色配合呼吸，不新增完整动作套装。

循环配乐加一个短收尾重音并淡出，给约 2 秒安静的停顿，然后显示问题。原网页继续保持锁定。

### 2.6 必须回答哲理问题

每次只显示一个问题。示例：

> 如果可以重新开始，你想改变什么？  
> If you could start again, what would you change?

2026-09-23 界面调整：保留当前网页的颜色，不叠加整页色罩、暗幕或背景模糊。问题使用约 380px 宽的白色小浮层，适配窄屏；仅显示问题、输入框和恢复按钮，删除品牌眉题、辅助说明和隐私说明。隐私说明仍在扩展设置中可见。右上角只保留一个声音图标，阶段提示仅供读屏，不再显示长条工具栏。破坏、等待和恢复阶段均不改变整页色调。

| 元素 | 中文 | English |
|---|---|---|
| 输入提示 | 写下你的想法…… | Write down your thoughts… |
| 提交按钮 | Done | Done |

交互规则：

- 只开放插件回答区域和声音控制，原网页仍不可操作。
- 空字符串、空格、纯换行及纯不可见字符不能提交。
- 非空白回答即可通过，不评分、不分析、不要求积极答案；「不知道」也是有效回答。
- 没有跳过、稍后回答、关闭问题或直接恢复入口。
- Esc、点击空白处、重复快捷键和等待超时均不能触发恢复。
- 没有倒计时；未回答时保持废墟状态。
- 中文输入法确认候选词时不能误提交。
- 怪兽保持轻微呼吸，不催促，也不提前入睡；不另做拨弄碎片动画。
- 回答不上传、不写入持久存储，触发恢复后清除。

### 2.7 提交与快速重建

有效提交后，输入框停止接收重复操作，问题淡出，播放柔和确认音。怪兽切换到静态修复姿势，配合轻微摆动或发光；不制作搬运、逐块扶正动作。

当前可见碎片自动归位；屏外已隐藏目标分批恢复，可用光效和短距离回滚串联。无需逐屏向上重演，更不先走到页面顶部。最后平滑返回召唤前的位置。

从接受有效回答到返回原位置并解锁，合计时长须满足 `T_restore <= min(T_destroy / 3, 12 秒)`。`T_destroy` 是第一击至废墟就绪的前台有效播放时间，不含准备、登场和答题等待。根据实际破坏时长调整归位、光效和返回滚动，不能通过固定最短动画突破上限。睡眠收尾不计入此预算，因为此时网页已解锁。

重建期间原网页继续锁定，重复提交只处理一次。恢复的是本次实际修改过的全部目标，不只是眼前一屏。

### 2.8 返回原位置与解锁

整页恢复后，自动回到召唤前的浏览位置，撤销插件施加的效果并解除操作锁。

用户可以继续点击、输入和滚动。原表单内容和网站事件绑定应保持有效，不通过刷新完成恢复。

如果网站自身在体验期间更新了内容，显示其当前状态，不强行回滚网站数据或重新插回已被网站删除的旧节点。

### 2.9 怪兽入睡与消失

页面解锁后，怪兽留在角落，打哈欠、蜷缩、入睡，随着呼吸逐渐透明。角色层不接收鼠标事件，不遮挡用户操作。

收尾乐句、轻呼吸逐渐淡出，最后完全静音。怪兽消失后回到待机，可再次召唤。

### 2.10 中断与异常

| 情况 | 处理 |
|---|---|
| 不支持的页面 | 启动前提示，不加操作锁 |
| 切换标签页 | 暂停滚动、动画和声音，返回后继续 |
| 等待回答时离开标签页 | 保留等待状态，不自动恢复 |
| 刷新、关闭或离开网页 | 本次会话终止，不拦截浏览器操作 |
| 单个声音加载失败 | 跳过该声音，视觉流程继续 |
| 主滚动容器被替换、严重布局失效 | 异常终止并清理，解除操作锁 |
| 动画执行故障 | 恢复插件隐藏的元素并清理，不留下被锁住的网页 |

异常清理与正常回答后重建是不同路径。等待用户回答本身不属于故障。

## 3. 技术方案

### 3.1 技术栈与模块

| 部分 | 方案 |
|---|---|
| 扩展 | Manifest V3 |
| 语言与构建 | TypeScript + Vite |
| 原元素动画 | Web Animations API |
| 局部碎片 | DOM、CSS 裁切与变换 |
| 角色 | AI 设计形象 + 分部件 SVG + JavaScript 关节与时间线；不依赖 After Effects 或 Lottie 主流程 |
| 特效 | Canvas 2D 与 CSS，本地打包资源 |
| 音频 | Web Audio API；优先验证 offscreen document 作为宿主 |
| 设置 | chrome.storage.local |
| 双语 | Chrome _locales 与应用文案表 |

后台 Service Worker 接收命令、检查页面、注入脚本、处理扩展消息。页面中的 Session Controller 持有动画、滚动、回答和恢复状态，不依赖后台常驻。

页面控制器包含：

- Page Analyzer：主滚动区域、内容范围和目标识别。
- Target Registry：目标引用、区域、状态、插件动画与碎片记录。
- Interaction Lock：操作屏蔽、焦点管理和清理。
- Scroll Director：长页面推进、暂停和原位置恢复。
- Monster Director：地面线、攻击带、左中右方向、动作可达性、屏数与时间预算；与滚动控制器共同推进目标。
- Destruction Engine：攻击顺序、碎裂与碎片运动。
- Monster Rig / Animator：部件层级、关节、动作关键姿势、时间线和命中事件。
- Monster Renderer：绘制分部件 SVG、应用关节姿态，与独立 Canvas 特效层对接。
- Question Panel：双语问题、输入与提交校验。
- Audio Manager：加载、循环、混音、暂停与释放。
- Recovery Manager：目标恢复和统一异常清理。

### 3.2 权限与快捷键

基础权限为 activeTab、scripting、storage；采用离屏音频宿主时增加 offscreen。首版不申请全站常驻访问、浏览历史、网络拦截或 debugger 权限。若启用透明扩展 iframe，对应入口与依赖按实际范围配置 web_accessible_resources，不宽泛暴露全部文件。

命令定义示意：

```json
{
  "commands": {
    "summon-monster": {
      "suggested_key": {
        "default": "Alt+Shift+D",
        "mac": "Alt+Shift+D"
      },
      "description": "__MSG_summonCommand__"
    }
  }
}
```

macOS 上 Alt 对应 Option。安装时通过命令查询接口检查实际绑定情况；面板显示实际生效的快捷键，不仅显示预设值。

### 3.3 直接操作原网页的约束

1. 不删除、移动、重新挂载原节点，不改写 innerHTML。
2. 已破坏内容保留原布局占位，不使用 display:none 抽掉内容。
3. 用独立动画实例实现短距离晃动、倾斜和透明变化。
4. 仅取消插件创建的动画，不取消网站自己的动画。
5. 有原始 transform 的元素须组合其变换或选择更简单的受击效果。
6. 只撤销插件的属性修改，不用旧的整段 style 覆盖网站后来产生的修改。
7. 大范围飞出、掉落由局部碎片承担，减少原节点变换造成的滚动溢出与父容器裁切。

### 3.4 攻击目标与局部碎片

按视觉结构选择攻击单元。卡片可整体攻击，也可拆内部内容，但不能同时把父卡片和内部节点作为重复破坏目标。body、html 和大型页面布局容器不整体倾倒。

一次攻击分为：原元素受击 → 局部碎片接替 → 原元素透明保留。

碎片在显示前完成创建，命中帧内同步显示碎片与隐藏原元素，避免重影。碎片接替后撤销原元素位移动画，仅保留透明效果，便于之后测量当前归位位置。

图片使用相同资源制作局部裁切片。文字优先验证「局部节点克隆 + 按行裁切」：保留必要的混排结构，固定源节点宽度和必要计算样式，再用 clip-path 裁出行区域。只克隆正在被攻击的局部内容，不复制整页。

cloneNode 不会冻结视觉。移动到不同祖先、Shadow DOM 或扩展 iframe 后，继承、选择器、CSS 变量、Web 字体和宽度可能改变。必须处理字体可用性、计算样式与伪元素，清除重复 ID、内联事件和可执行内容；输入框等交互元素转换为无行为的局部视觉表示。不能把「克隆即可自动保真」当作事实。

阶段一在微信公众号文章、知乎、一个英文博客验证中文、英文、链接、加粗、混排和 Web 字体的裁切效果，并配备可重复的本地测试页。多行内容不默认每一行复制完整大段 DOM；根据实测限制克隆规模，必要时简化切片粒度。

初始数据结构示意：

```ts
type TargetState = "intact" | "attacking" | "destroyed" | "restoring" | "restored";

interface DestructionTarget {
  id: string;
  element: HTMLElement;
  kind: "text" | "image" | "card" | "button" | "structure";
  state: TargetState;
  ownedAnimations: Animation[];
  fragmentIds: string[];
}

interface Fragment {
  id: string;
  targetId: string;
  x: number;
  y: number;
  rotation: number;
  vx: number;
  vy: number;
  state: "falling" | "settled" | "restoring";
}
```

碎片使用轻量重力、阻尼、反弹与有限碰撞。首版重点是动作对应、碎片来自原内容和可恢复，不先做复杂任意多边形物理。

### 3.5 滚动与动态页面

优先使用主文档滚动区域；只有主要正文明确位于独立容器时才选择该容器。多重候选无法可靠区分时提示暂不支持。

保存初始内容范围、原滚动位置和视口尺寸。从当前视口开始，由 Monster Director 与 Scroll Director 统一计算目标进入攻击带的时机、停留时间、攻击方向和滚动速度，避免各自运行独立时间线。

每个动作配置可达范围和命中标记。目标进入相应范围并到达命中时刻，才触发破碎和音效；未进入范围不允许隔空爪击。大目标使用尾扫或吐息。控制器同时跟踪已推进视口高度和前台时间，提前进入 FINAL_BLAST；屏外批量处理也受目标规模预算约束，无法可靠登记全部本轮目标时应在准备阶段拒绝或提示不支持，不能偷偷漏掉内容。

普通文档使用内容坐标减去滚动偏移得到视口坐标；独立容器还要加容器偏移与裁切。固定和 sticky 元素单独处理，避免每屏重复出现或重复破坏。

攻击前重新测量元素。观察必要的布局变化，但不每帧扫描整页。无限加载的新内容不扩展本轮范围；虚拟列表节点复用必须通过适配解决。

隐藏滚动条时补偿可能变化的可用宽度，避免文本换行改变。临时调整 scroll-behavior、滚动吸附等属性时记录原值，结束时撤销。

### 3.6 操作锁与透明效果层

基线方案使用透明全屏模态 dialog 承载局部碎片、角色渲染器、Canvas 特效和问题界面，真实网页仍从透明区域可见。使用 Shadow DOM 隔离插件样式，明确设置 dialog 默认样式和透明 backdrop。

透明扩展页 iframe 作为阶段一对照方案，用于验证角色、问题面板和音频在扩展来源下的行为。它不能直接操作宿主 DOM；页面分析、原节点动画和必要的局部碎片仍由内容脚本管理，通过经过来源与会话校验的消息同步坐标和事件。需要验证叠层顺序、字体隔离、焦点、资源访问和消息延迟；不预先承诺一个 iframe 自动解决音频、WASM 和样式的全部问题。

模态机制负责基础焦点与背景交互限制，再补充滚轮、触摸、键盘滚动、拖动、选择文字和 Esc cancel 事件处理。原滚动条隐藏，程序化滚动保留。

该机制只控制网页内容区，不是对恶意宿主页面的安全隔离，也不控制浏览器级快捷键。已有网页模态框、顶层元素和全屏模式需要实际测试；无法可靠控制时不启动。

问题阶段只开放回答与声音控制。关闭模态层之前先完成恢复和原位置回归；睡眠角色转入 pointer-events:none 的普通层。

### 3.7 状态机

```text
IDLE → PREPARING → SUMMONING
     → DESTROYING → [FINAL_BLAST] → RUINS → AWAITING_ANSWER
     → RESTORING → RETURNING → SLEEPING → IDLE
```

页面会话以唯一 sessionId 防止重复启动和过期异步结果污染新会话。只有 AWAITING_ANSWER 状态的有效提交能进入 RESTORING，不能用音乐结束事件或任意计时器触发。

界面禁用提交按钮之外，提交处理器还必须再次校验。进入恢复状态后不再接受回答事件。

严重异常进入 ABORTING，统一清理后结束。切换标签页属于暂停，保存当前状态，不改变业务阶段。

### 3.8 恢复与清理

恢复在时长预算内完成。当前可见碎片停止物理模拟，按原节点的当前有效位置归位；屏外和吐息批量隐藏的目标分批撤销效果，不生成额外恢复碎片。完成所有目标恢复后返回原位置再解锁，不强制逆向巡游整篇页面。

网站自行移除的节点不重新插入；网站数据不整体回滚。焦点元素仍存在且可用时再恢复焦点。

cleanup 必须可重复调用，负责取消插件动画、撤销自身样式修改、移除覆盖层、解除锁定、取消异步任务、清理观察器与事件、停止声音并释放资源。只处理属于当前会话的对象。

### 3.9 性能策略

- 只激活当前区域和相邻区域的碎片与特效。
- 已沉降或离开视口的碎片停止逐帧模拟，保留恢复所需记录。
- 按批次读取布局，再批次写入动画样式。
- 长正文默认按行或词组，不全篇逐字生成节点。
- 优先降低尘埃、碎片数量和震动强度，保留完整流程。
- 根据原型测量确定目标数、碎片数和内存预算，超出支持规模时明确提示，不悄悄只处理第一屏。

### 3.10 首版角色制作路线

首选「AI 设计角色 + 分部件 SVG + 前端程序动画」。AI 用于开发阶段的角色设计和素材辅助，插件运行时只使用打包后的本地文件，不在线生成角色。前端负责关节变换、时间线与动作事件，不要求使用 After Effects、Bodymovin 或 Lottie 导出。

#### 3.10.1 从设计图到可动部件

```text
AI 生成角色设计候选
 → 确定统一外形与略侧身视角
 → 按定稿整理或重绘分部件 SVG
 → 建立关节、层级和接触点
 → 制作爪击、尾扫小样并在网页验证
 → 扩展其余三套动作
```

AI 生成的完整图片不是可直接使用的骨架。需要整理轮廓、拆分部件、补全遮挡区域和设置关节；若设计图是位图，应根据定稿以代码或矢量工具重绘、简化为 SVG，不承诺自动转矢量即可达到质量要求。

优先使用分部件 SVG 保持粗线条卡通风格、清楚轮廓与缩放效果。如果个别视觉细节必须用透明 PNG，记录为混合素材，并检查透明边缘和缩放清晰度；不默认改用整段视频或逐帧精灵图。

建议部件包括躯干、头部、眼睛与眉毛、下颌、左右手臂和爪子、左右腿、尾巴若干节段、背鳍。各部件留出关节重叠区，补画被遮住的形状，抬手和转头时不能露出空洞。

记录角色设计稿、分层素材、使用的生成工具或素材来源及必要的生成参数，保证同一角色可继续修改。AI 视觉路线不改变音频规则：音频仍先找可商用素材，找不到先询问用户，不能因此自行生成音乐或音效。

#### 3.10.2 前端关节与绘制

SVG 采用统一 viewBox，用嵌套 g 分组形成父子结构。肩膀、脖子、下颌、髋部和尾巴根部设置明确旋转中心；尾巴采用串联节段产生延迟摆动。左右手臂、下颌等子部件跟随父部件变换，不独立漂移。

前端保存 rig 配置：部件 ID、父级、轴心、初始姿态、绘制顺序、角度范围，以及爪尖、尾尖、嘴部的局部坐标。通过角色缩放、朝向和关节变换，把接触点换算为视口坐标，与攻击带中的真实目标对齐。

动作由 JavaScript 时间线驱动，使用 requestAnimationFrame 应用计算后的姿态。等待呼吸、背鳍发光等轻效果可以使用 CSS 或 Web Animations API，但不能让多套动画同时争夺同一部件的变换。

左右攻击通过镜像和小幅关节调整复用；中间方向在既定略侧身视角内转向，不假装镜像能生成完整正面或背面。复杂透视变化、大幅转身和身体弯曲不作为首版要求。

#### 3.10.3 五套动作与命中事件

| 动作 | 关键姿势与程序控制 | 事件 |
|---|---|---|
| 登场 | 整体移入、落地压缩、回弹站稳 | 落地声、轻震动 |
| 爪击 | 身体后仰、抬爪、快速挥下、命中停顿、收回 | 爪尖命中目标时触发破碎与撞击声 |
| 尾扫 | 躯干蓄力、尾部各节依次甩出、回弹 | 尾尖或扫掠范围进入目标时触发成片破坏 |
| 吐息 | 背鳍逐片亮起、张嘴、身体后坐、结束复位 | 蓄力、从嘴部接出的喷射、余音 |
| 睡眠 | 身体降低、可选哈欠、闭眼、尾巴收拢、缓慢呼吸 | 哈欠或轻呼吸、淡出 |

爪击替代独立撕咬与踩踏；等待呼吸和修复姿势用静态素材加轻微变换与光效。取消逐目标行走与搬运动画，不把修复另算成第六套完整动作。

每套动作定义持续时间、关键姿势、缓动、可达范围和事件标记。前摇相对缓慢，挥动快速，接触时短暂停顿，随后收势；参数通过实机观看与试听调整，不以动画时长或帧数多作为质量指标。

统一会话时钟推进动作。当进度跨过命中标记时只触发一次；掉帧也不能漏触发，暂停恢复或重播不能重复触发旧事件。动作被取消时清理尚未发生的事件。吐息光束、裂纹、烟尘和网页碎片由独立效果层生成，起点跟随嘴部或爪尖，不能把这些效果烘焙进固定背景的角色视频。

#### 3.10.4 原型门槛与备选

阶段一交付同一只怪兽的静态形象、一次爪击、一次尾扫，放到真实网页并接入初选命中音效。检查实际显示尺寸下的轮廓和表情、关节穿帮、脚掌滑动、命中位置和动作力量感；通过后再扩展登场、吐息、睡眠。

若程序关节动画的纸偶感明显、动作不自然，先调整轮廓、关节重叠和关键姿势。仍不能达到效果时再评估 Lottie 制作或精灵图，不在首版同时维护多套引擎。AI 逐帧图和 AI 视频提帧只作后续候选，需要额外解决外形一致性、透明背景、循环和接触时刻；像素风属于视觉变更，不自动采用。

Rive 不作为首版依赖，主路线不需要 WASM。以后若选用，仍须区分隔离世界内容脚本、主世界和扩展页面的 CSP，验证本地资源及运行上下文，不能仅凭引擎类型判断兼容性。

### 3.11 双语题库与抽取

产品侧负责 50 道中英对照题，附录 A 已提供初稿，当前 Agent 承担初稿整理，产品侧在阶段三定稿。阶段一即可接入初稿验证问题长度、语气与输入体验；不把题库推迟到最后填充。

每题使用稳定 ID、主题和 zh/en 文案。采用本地洗牌袋，一轮 50 题用完前不重复；新一轮避开最近展示的题。仅保存题目 ID 和抽取状态，不保存回答。切换语言展示同一题的翻译，不重新抽题。短句、无标准答案、不说教，不要求用户披露个人隐私。

## 4. 音乐与音效方案

### 4.1 素材筛选与交付原则

音乐和音效是正式交付项，需要提供真实文件、接入效果和试听结果，不以占位文件名代替。

首版优先使用可商用素材，工作以挑选、剪辑、调音量和接入为主，原创音频制作不作为交付项。当前尚未完成具体素材的筛选与授权核验。

查找顺序建议为 Kenney、Freesound 的 CC0 素材，再考虑 Sonniss GDC 免费包、Pixabay 等明确许可的来源。逐个核对实际素材及下载包许可，不把整个平台视为统一授权。避开 CC-BY-NC；使用 CC-BY 时在关于页及 asset-sources.md 中落实作者、链接、许可与修改说明。

怪兽叫声、吐息等难找的素材也先搜索。找不到合适素材时，整理缺口、已有候选和替代方案询问用户；未经用户针对该方案确认，不自行调用 AI 生成或购买素材。

五类音乐内容优先从同一作者或同一素材包剪辑组合，减少音色割裂，不要求购买或制作五首独立完整音乐。初选素材及其来源记录在阶段一末尾接入原型，尽早验证声音与动作的手感。

配乐不含歌词，音效不含语言对白，中英文共用。声音随流程从卡通力量感转向安静、柔和，不用越来越急的提示音催促回答。

### 4.2 配乐清单

| 素材 | 声音方向 | 规则 |
|---|---|---|
| 召唤乐句 | 低音上行、短鼓点 | 登场时一次 |
| 摧毁配乐 | 弹性低音、打击乐、顽皮旋律 | 循环，最后一击后结束 |
| 废墟环境底音 | 很轻的空气感、稀疏音色 | 等待回答时低音量循环 |
| 重建配乐 | 柔和键盘、拨弦、舒展节奏 | 回答后循环，重建完成后结束 |
| 入睡乐句 | 简短、温暖、自然衰减 | 睡眠阶段一次 |

摧毁与重建使用「循环段 + 短收尾重音 + 淡出」，取消专门制作或寻找结束段的要求。音乐转场服从状态机，不能为了等乐句结束而突破 60 秒破坏或快速恢复的预算。

循环使用两个音源交叉淡入淡出，但仍需挑选和剪辑合适区间，检查节拍、和声和旋律句尾。交叉淡化能处理波形接缝，不能保证任意一段音乐都能自然循环。

### 4.3 音效清单

| 类别 | 素材 | 触发 |
|---|---|---|
| 登场 | 出场、落地、短低吼 | 进入、落地帧 |
| 登场接地 | 轻脚步、重落地，可复用已有素材 | 登场的脚掌落地，不制作独立行走音轨 |
| 爪击 | 破风、命中 | 挥动与接触分别触发 |
| 尾扫 | 扫动、成片撞击 | 尾巴扫中目标 |
| 文字 | 细碎断裂、颗粒落地 | 文字破碎与沉降 |
| 图片 | 纸张或薄片撕裂 | 图片碎裂 |
| 卡片 | 结构断裂、沉重倒塌 | 卡片倾倒 |
| 吐息 | 蓄能、持续喷射、余音 | 吐息三个阶段 |
| 废墟 | 碎屑沉降、喘气 | 最后一击后 |
| 提问 | 轻提示音 | 问题首次出现 |
| 提交 | 柔和确认音 | 有效提交 |
| 重建 | 回升、拼合、归位 | 碎片自动恢复与修复光效 |
| 入睡 | 哈欠、轻呼吸或轻鼾 | 趴下与睡眠 |
| 消失 | 轻柔收尾声 | 淡出 |

脚步、命中、碎裂、拼合等高频音效准备多个变体，避免机械重复。

### 4.4 音频系统

Audio Manager 使用 Web Audio API，由状态机、怪兽动作事件和碎片事件共同驱动。优先验证 MV3 offscreen document 音频宿主；内容脚本通过扩展消息驱动。准备阶段预加载资源，攻击时不临时读取远程音频。

```text
音乐轨 ───────┐
环境音轨 ─────┤
怪兽音效轨 ───┼→ 总音量 / 静音 → 输出
破坏与重建轨 ─┘
```

短音效和循环段预解码为 AudioBuffer，使用音频时钟调度。循环的 A/B 两个播放源在候选接缝区交叉淡化，并检查叠加峰值和节拍；渐变时长随音乐剪辑结果设定，不统一硬编码。素材参数表记录路径、类别、循环区间、交叉淡化时长、默认增益、变体、并发上限和触发间隔。

离屏宿主是扩展共享资源，按 tabId、sessionId 隔离消息和播放句柄，避免多标签页串音。一次动作发送包含前摇与命中时刻的事件计划，在音频时钟上提前调度，实际测量消息延迟和画面偏差；不假设 runtime 消息具有逐帧实时保证。

命中声绑定接触帧；脚步绑定落地帧。不要为每一块碎片分别播放声音，按攻击或碎片组触发。重击和吐息出现时暂时降低配乐，再平滑恢复。

对高频音效随机选择变体，可小幅调整播放速度和音量；按屏幕横向位置加入轻微左右声像。音乐转场和静音均使用音量渐变。

### 4.5 声音设置与播放限制

提供声音总开关、音乐音量、音效音量和试听按钮，设置本地保存。具体默认音量在试听后确定。

体验期间保留插件自己的静音按钮，不解锁网页、不绕过回答。

阶段一在全新浏览器配置、首次访问网页、首次快捷键启动的条件下验证声音。对比内容脚本 AudioContext、offscreen document，以及透明扩展 iframe 的候选路径，记录自动播放、焦点、CSP、资源访问和动作同步结果。优先选择能可靠完成首轮有声体验且复杂度较低的宿主，不预先写成「扩展页面一定不受自动播放限制」。

offscreen 需要额外权限，同一普通配置中通常只能存在一个离屏文档。以 AUDIO_PLAYBACK 原因创建时，30 秒没有音频播放会关闭，静音或切走较久后要检查并按需重建；不能播放无意义的静音音轨强行保活。恢复位置、当前阶段与主音量由会话控制器保存，重建宿主后补齐当前状态，不补播旧攻击。实现关闭标签、异常退出及消息失联后的停止机制，避免无人管理的后台声音。

自动播放兜底仍保留「开启声音 / Enable sound」按钮，视觉流程不因音频失败卡住；该入口是异常兼容兜底，不是默认把首次体验设计成静音。正常首次快捷键有声播放是否通过，必须写入测试记录。

切换标签页时暂停音频调度并保存音乐位置。返回后不补播错过的攻击音效。重用 AudioBuffer，但需要时创建新的播放节点。

单个素材失败不阻断主流程；会话结束或异常时停止所有音源和待播放事件。不自动静音或改动原网页的音视频。

### 4.6 音频资产交付

```text
assets/audio/
  music/
  monster/
  destruction/
  restoration/
  ui/
  manifest.json
```

只打包压缩版本，优先验证 Opus，AAC 作为备选；通过解码和听感测试后确定实际容器、编码与质量，避免默认重复打包两套。发布音频文件合计不超过 3 MB（按 3,000,000 字节检查）。不要求交付无损母版。

asset-sources.md 逐项记录原始页面、作者、下载时间、许可链接或随包许可证据、剪辑与转码说明、署名文本和最终文件映射。关于页显示需要署名的素材。开发时依法保留必要的来源与许可证据，发布包只包含实际需要的音频与说明。

交付压缩素材包、来源记录、事件映射和串联试听样例；试听样例不重复放入插件发布包。3 MB 是编码文件预算，解码后的 AudioBuffer 内存另行测量和限制。

验收包括实际解码后的循环接缝、无削波与突兀音量变化、声音与动作同步，以及长时间重复播放的听感。程序检测不能代替主观试听。

## 5. 支持范围与技术风险

| 类型或问题 | 处理策略 |
|---|---|
| 普通文章、常规布局 | 首版核心验收对象 |
| 表单与 contenteditable | 原状态保留与输入阻断必须单独测试 |
| 已有 CSS 变换、动画 | 保留网站动画，验证叠加；必要时简化受击 |
| 固定与 sticky 元素 | 单独分类，不重复破坏 |
| 单一独立滚动容器 | 坐标与裁切适配后支持 |
| 多重滚动容器 | 无法可靠识别时提示不支持 |
| 虚拟列表 | 节点复用会破坏引用假设，需要专项适配 |
| Canvas、视频、跨域 iframe | 可验证整体元素受击，不承诺内部精细碎裂 |
| 懒加载图片、动态更新 | 攻击前重测，重大变化时安全终止 |
| Chrome 内置或受限页面 | 启动前拒绝注入并提示 |
| 浏览器缩放、窗口尺寸变化 | 坐标可重算则暂停重算，否则异常清理 |
| 插件卸载、更新、标签页丢弃 | 专项测试生命周期，不承诺脚本消失后仍能执行清理；刷新是浏览器级恢复途径 |
| AI 形象与 SVG 部件 | AI 图片不是骨架；需要重绘整理、补遮挡和设关节，验证实际尺寸下的轮廓与一致性 |
| 程序角色动画 | 原型验证纸偶感、关节露缝、脚滑、命中坐标和暂停恢复；复杂转身不纳入首版 |
| Lottie / Rive 等备选 | 仅在主路线效果不达标时评估，不进入默认依赖或必做验证清单 |
| 克隆裁切的字体与混排 | 在微信公众号文章、知乎、英文博客及本地固定样本对照验证 |
| 离屏音频生命周期 | 首次快捷键、静音或切走超过 30 秒、多标签页与宿主重建专项验证 |
| 超长页面 | 常规破坏有屏数与时间上限；剩余目标吐息批处理，并验证全部恢复 |

## 6. 开发计划

按阶段推进，不在关键可行性未验证前投入完整角色制作。音频初选与接入、题库初稿均提前到阶段一；以下按交付物与通过条件管理，日历工期在原型完成后估算，不把「几天完成」作为未经验证的承诺。

### 阶段一：技术验证、初选音频与题库接入

**工作内容**

- 建立独立扩展工程与跨平台构建入口。
- 实现默认快捷键、页面注入、单会话控制和双语基本提示。
- 在包含文字、图片、表单的长测试页上实现原元素受击、隐藏与恢复。
- 实现当前视口启动、操作锁、攻击带雏形、自动向下推进、有效回答后快速恢复。
- 实现返回原位置、暂停和异常清理。
- 用 AI 完成角色设计候选，整理同一形象的分部件 SVG，建立前端关节配置；完成一次爪击、一次尾扫及命中标记，配初选音效在真实网页验证，不先制作全套动作。
- 在全新浏览器配置首次快捷键启动下，对比音频宿主；验证 offscreen 静默 30 秒后的生命周期、跨标签隔离及消息同步。
- 对透明扩展 iframe 做最小对照验证，记录与基线的差异后选择宿主，不默认拆分全部 UI。
- 在微信公众号文章、知乎、英文博客验证克隆裁切的字体与混排保真，并保存本地可重复样本和对照截图。
- 阶段末接入查找并核对来源的第一批音乐与核心攻击音效，进行一次带声音的真实体验。
- 产品侧从附录 A 的 50 道双语题初稿开始审阅，接入不重复抽取机制。

**交付物**：可加载且能试听的原型、角色设计稿与分部件 SVG、关节配置及爪击/尾扫小样、测试页面、三站视觉对照、音频与角色运行验证记录、初选素材来源表、题库初稿。

**通过条件**：当前视口起步的完整流程跑通；未回答不能恢复；表单和事件绑定保留；没有残留操作锁；角色爪击与尾扫在实际尺寸下形象清楚、关节无明显露缝，命中与声音对应；首轮快捷键音频与文字碎片保真有真实证据。未通过的核心体验必须修正或明确收窄支持范围，不能用占位音效或口头推断验收。

### 阶段二：攻击带、节奏与快速重建

**工作内容**

- 实现目标分类、父子去重、文字与图片碎片。
- 完成地面线、攻击带、左中右方向和爪击、尾扫、吐息的事件驱动破坏。
- 实现默认 6 屏、参数上限 8 屏及含收尾不超过 60 秒的控制，处理起点上方和下方剩余内容。
- 实现静态修复姿势、自动归位与快速回原位置，重建总时长满足破坏的三分之一以内且最多 12 秒。
- 完成主文档、固定导航及单一独立滚动容器适配。
- 建立视口附近渲染和碎片数量控制。

**交付物**：带初选音频的节奏原型、支持范围清单、分阶段时长与性能测量记录。

**通过条件**：攻击范围和命中对应；精细区与吐息收尾衔接清楚；没有未登记的残留隐藏目标；长页和短页均满足时长预算，答题等待不计入预算且不被强制结束。

### 阶段三：五套角色动作、音频与题库定稿

**工作内容**

- 定稿 AI 辅助设计的卡通形象和分部件 SVG，完善前端关节配置与动作时间线，只制作登场、爪击、尾扫、吐息、睡眠五套完整动作；等待呼吸和修复姿势采用轻量程序动画。
- 在第一批声音基础上配齐五类音乐内容和首版核心音效；优先同作者或同包，进行挑选、剪辑、调音量。
- 配齐高频音效变体，以循环段、交叉淡化和收尾重音实现音乐转场，不另做结束段。
- 来源逐项入表，发布音频仅保留压缩版，总体积不超过 3 MB；素材缺口先询问用户，不自行转 AI 生成。
- 产品侧定稿 50 道中英对照题，检查翻译、主题分布、长度、不说教和无重复；附录 A 是初稿，不当作已审定内容。
- 制作独立试听样例，调整力量感、安静感和收尾情绪；试听结果与机器检测分开记录。

**交付物**：角色设计来源记录、可编辑分部件 SVG、rig 配置、五套动作时间线与事件标记、完整压缩音频包、asset-sources.md、试听样例、50 题双语定稿。

**通过条件**：无占位素材；动作量未膨胀；画风与音乐音色统一；循环听感成立；许可与署名完整；音频体积达标；题库可按 ID 不重复抽取。

### 阶段四：产品整合

**工作内容**

- 将角色命中帧、碎片事件和音效接入同一流程。
- 完成交叉淡化循环、收尾重音、转场、配乐让位和音效并发控制。
- 完成中英文面板、题库、错误提示、语言与音量保存。
- 完成已验证的音频宿主及重建逻辑；保留浏览器阻止声音时的异常兜底入口。
- 完成睡眠层不遮挡操作、静音与完整资源释放。

**交付物**：可完整体验的候选版本、更新后的说明与支持范围。

**通过条件**：从召唤到退场完整一致；切换标签页和重复运行无声音或视觉残留。

### 阶段五：兼容测试与打包

**工作内容**

- 在自建测试页和选择的真实网站验证。
- 覆盖 Windows 与 macOS 的快捷键、输入法和声音行为；Linux 可用性单独记录。
- 验证不同窗口尺寸、缩放比例、长页面和低性能条件。
- 检查权限、资源打包、素材来源与无外部音频依赖。
- 检查最终音频文件总字节数、首次快捷键有声体验，以及长页与短页的时长预算。
- 打包可加载扩展，整理安装说明、已知限制和测试报告。

**交付物**：扩展安装包、源码、构建说明、用户说明、素材包、验收报告。

**通过条件**：下面的核心验收项全部通过；未测平台明确标注，不将推测兼容当作实测。

Chrome 商店公开发布不作为本阶段自动动作，需另行完成商店材料与发布安排。

## 7. 核心验收清单

### 7.1 用户流程

- [ ] 安装后有默认快捷键，冲突时提示，面板按钮可召唤。
- [ ] 在页面中部启动后第一击发生在当前视口，不先回顶部。
- [ ] 怪兽保持在地面线附近，目标进入攻击带后才命中，支持左中右方向。
- [ ] 精细破坏默认最多约 6 屏、参数上限 8 屏，超出内容以吐息集中处理，含起点上方未经过内容。
- [ ] 第一击到废墟就绪含吐息不超过 60 秒前台有效时间，切走暂停不消耗预算。
- [ ] 破坏、等待与重建期间，原网页不能被鼠标或键盘操作。
- [ ] 空白回答无效，没有跳过、Esc 绕过或超时恢复。
- [ ] 有效回答只触发一次恢复，输入法确认不误提交。
- [ ] 有效提交至返回原位置并解锁不超过实际破坏时长的三分之一，且最多 12 秒；不逐屏重演。
- [ ] 50 道题中英文按 ID 对应，一轮不重复，新一轮避开最近题，不持久保存回答。
- [ ] 解锁后原表单、链接、按钮和网站事件继续工作。
- [ ] 怪兽睡眠、淡出期间不遮挡点击。
- [ ] 刷新、关闭和切换标签等浏览器操作保持可用。

### 7.2 视觉与工程

2026-09-22 用户补充：**“好不好看”是独立验收标准**。由 Claude Code 的 `effects-reviewer` 独立评价实际渲染的造型、配色、层次、火焰与嘴部衔接、动作节奏和网页中的整体观感，按反馈修改后复评。代码正确、测试通过、音频能播放，均不能代替视觉认可；不得用概念图代替插件实际效果。审查者没有看到动画或听到声音的部分必须标为待验证。

- [ ] 吐息在实际显示尺寸下有清楚的蓄力、喷出、火舌流动与消散；与怪兽卡通画风统一，不像简单激光线或拉伸纸片。
- [ ] Claude Code 对实际渲染的视觉审美单独给出理由与结论，阻断问题经过修改和复评；用户对观感的反馈优先。

- [ ] 原节点不被删除、重新挂载或整体替换。
- [ ] 已破坏内容保留布局占位，页面高度无破坏导致的塌缩。
- [ ] 文字、图片碎片可辨认来自原页面。
- [ ] 微信公众号文章、知乎、英文博客的克隆裁切验证有对照结果，并覆盖 Web 字体和混排。
- [ ] AI 角色设计稿、可编辑分部件 SVG、关节配置与程序时间线完整，首版不依赖 AE 或 Lottie 导出。
- [ ] 角色只有五套完整动作，等待与修复不额外扩成动作套装，修复无搬运要求。
- [ ] 实际显示尺寸下形象一致、关节无明显露缝或穿帮；爪击、尾扫的力量感有观看与试听记录。
- [ ] 爪尖、尾尖、嘴部接触点与真实目标及特效对应；掉帧、暂停恢复和动作取消不漏发或重复命中事件。
- [ ] 动画清理不取消网站自己的动画或覆盖其新状态。
- [ ] 连续多轮使用无残留隐藏元素、覆盖层或操作锁。
- [ ] 异常时能够清理并恢复可操作状态。
- [ ] 长页面的资源使用受控，不持续累积逐帧运行对象。
- [ ] 支持范围、未测情况和已知限制如实记录。

### 7.3 音乐与音效

- [ ] 所有核心阶段都有对应真实素材与事件映射。
- [ ] 素材来源和许可逐项记录，必要署名出现在关于页；找不到合适素材时先询问用户，未擅自 AI 生成。
- [ ] 发布音频合计不超过 3,000,000 字节，不打包无损母版；解码内存单独测量。
- [ ] 同作者或同包优先，跨音轨音色协调；交叉淡化同时通过波形接缝与节拍和声听感检查。
- [ ] 新配置、首次访问、首次快捷键的有声体验已验证，不以长期使用后的自动播放授权代替。
- [ ] 离屏音频静默超过 30 秒后能按需恢复，多标签页不串音，会话结束无后台残响。
- [ ] 脚步、挥动、命中、吐息、碎裂声音与动作同步。
- [ ] 长页面循环无明显空隙、接缝点击声或机械重复。
- [ ] 等待回答时声音安静，不催促、不提前进入重建音乐。
- [ ] 叠加播放无明显削波，音量切换平滑。
- [ ] 静音立即生效且不改变回答规则。
- [ ] 切换标签页不在后台持续播放，返回后不集中补播音效。
- [ ] 怪兽消失后无残余声音，下一轮不叠加旧音乐。
- [ ] 通过技术检查和主观试听，二者均有记录。
