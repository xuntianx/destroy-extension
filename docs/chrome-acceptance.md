# Chrome 实装验收单

更新时间：2026-09-23。适用版本：0.1.0 开发版。用户已确认“可以召唤怪兽，也有声音”和“快捷键可用”；这三项基础可用性已有用户实装反馈。Claude Code第四轮另已认可视觉与审美（整体8/10），原文见[独立评审记录](reviews/2026-09-22-claude/README.md)。仍未确认全新配置首次播放条件、完整声音听感及下面的生命周期与兼容性项目；不要求用户重复确认已有事实，也不把本地演示和单元测试当作全部实装通过。

## 准备

按 [安装说明](installation.md) 加载含有 manifest.json 的构建目录。更新构建后，刷新扩展，再刷新测试网页。

开发者在本项目目录执行 `npm ci`、`npm run dev`，然后在 **Chrome** 打开终端给出的本地地址，加上 `/tests/fixtures/extension-host.html`。该页面只包含网页内容、草稿和计数按钮，不包含 Session、AudioMixer、快捷键监听或模拟 Chrome API。它不会自己召唤怪兽。

也可以使用构建后的固定测试站点：`npm run fixture:build`，然后用静态 HTTP 服务托管 `artifacts/fixture/`，打开相同路径。不要通过 file 地址测试第一轮，也不要把 `/tests/fixtures/article.html` 上的本地演示按钮当作扩展已加载的证据。

首次快捷键声音需要一个尚未给页面积累播放许可的测试配置：记录是否新建配置、是否首次访问、是否此前点击过声音试听。安装管理操作由用户在 Chrome 完成；插件面板的召唤按钮是另一条入口，不能替代快捷键验证。

## 先验证一次完整体验

| 步骤 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 1 | 点击测试页的「去页面中部测试」，改写草稿，点击一次计数按钮 | 草稿有内容，计数为 1，页面停在中部 |
| 2 | 按 Alt+Shift+D；macOS 按 Option+Shift+D | 当前视口出现同一只怪兽并有登场声音，第一击不先跳到顶部 |
| 3 | 观看破坏，尝试点击原网页按钮和修改草稿 | 页面自动向下滚动；原网页操作被锁定；最后吐息覆盖剩余已登记内容 |
| 4 | 等待问题出现；尝试空白输入、Escape，再等待一会儿 | 不进入恢复；没有跳过按钮；等待本身没有倒计时结束 |
| 5 | 用中文输入法完成一个回答，再提交 | 输入法选词不会误提交；有效提交只触发一次恢复；回答文字不出现在原网页 |
| 6 | 等待快速恢复，再检查草稿、计数和链接 | 回到原位置，草稿原样保留，计数仍为 1；点击后变成 2，链接可用；睡眠和淡出不挡操作 |

记录破坏和恢复的实际时长。破坏预算从第一击到废墟就绪计算，最多 60 秒前台时间；恢复从有效提交到回原位置并解锁计算，不超过破坏时长三分之一且最多 12 秒。答题等待不计入二者。

## 再验证最容易出错的情形

- **后台与声音**：在破坏中切去另一个标签，停留至少 35 秒，再返回。后台没有继续播放；返回后从当前阶段继续，没有连发旧命中。另测等待问题时静音超过 35 秒，再开启声音。不能据此单独证明 offscreen 已被 Chrome 回收，宿主重建需结合扩展诊断证据。
- **多个标签**：两张普通网页分别使用插件，切换活动标签。声音、答案与恢复各属于自己的页面，不能错恢复另一页。
- **多轮与异常**：同一网页完成三轮；每轮都检查草稿和按钮。另测窗口尺寸变化和页面刷新，记录是否残留覆盖层或操作锁。浏览器刷新／关页是浏览器操作，不是产品跳过入口。
- **真实排版**：微信公众号文章、知乎文章、英文博客各选一页。保留原文、文字命中、图片碎裂、恢复后的对照；至少覆盖一处 Web 字体和中英文混排。不要把本地仿文当成三站验证。
- **视觉与听感**：分别看登场、爪击、尾扫、吐息、睡眠。记录纸偶感、关节露缝、脚滑、命中错位；听长循环接缝、叠加音量、归位变体、安静等待和结束残响。描述具体哪个动作／声音不合适。
- **设置与平台**：检查中英文切换、音量与静音保存、实际快捷键和冲突提示；分别记录操作系统、Chrome 版本、输入法、缩放、窗口尺寸与低性能条件。未测平台保持未测。
